# XIAOSI-OS

熊舒辉崎（小四）的浏览器桌面式个人站。本项目是本地静态站，不包含部署操作。

默认内容已经接入三套代表项目：中国挂面村品牌策划、红旗 HS3 年轻化营销、三九胃泰整合传播概念。首页和项目页面使用的是公开候选素材；成绩单、原始证书、电话及第三方个人信息没有写入网站。

## 本地预览

在当前目录的上一级运行：

```bash
python3 -m http.server 8000 --directory xiaosi-os-portfolio
```

打开 `http://localhost:8000/`。

## 后续补内容

- 普通浏览：`http://localhost:8000/`
- 编辑入口：`http://localhost:8000/?edit=1`
- 文字会保存在浏览器 `localStorage`。
- 壁纸、头像和项目图片会保存在浏览器 `IndexedDB`，并覆盖项目内置的默认图片，只用于本机预览。
- “导出内容 JSON”可导出文字配置；正式上线前仍需把确认后的图片复制到 `assets/` 并更新默认配置。
- 默认文字位于 `content.js`，默认壁纸与头像位于 `assets/`。

## 当前可交互内容

- About Me：桌面端保留 8 张可拖动窗口，并提供一键收起；手机横屏使用单个可滚动窗口。
- 手机以横屏浏览，竖屏显示旋转提示；横屏桌面图标、项目菜单与窗口适配较矮的屏幕。
- 项目图片点击可放大查看，用左右按钮或方向键切换，按 Esc 返回。编辑模式在查看器中提供替换图片按钮。
- 编辑面板可修改项目名称、简介及小节文字；修改后先保存再切换项目，重新打开作品窗口即可查看。
- 上传的视频重新打开窗口仍可播放，使用独立的替换按钮和原生播放控件。
- 三个项目文件夹：双击后从桌面展开完整案例、调研、策略、视觉、活动、图片、视频和证据档案入口。
- README：自动记录 7 个探索任务的完成状态。
- 壁纸人物：点击后切换到无人版桌面。
- 图片集与 Video：编辑模式下可上传本机图片或视频进行预览。
- Internet：内置三个项目书签和搜索占位。

## 新增游戏与内容槽

- **小四扭蛋机**：转动把手抽取已填好的内容，本轮优先抽未遇见的展位；支持详情、收藏、再次抽取。空机可试转，但只显示补货提示，不生成虚构内容。
- **小四小镇**：星露谷氛围的原创 Canvas 像素小镇，跟随镜头、木屋与瓦顶、草地小径、果树、池塘水波、角色行走与攻击动画。未使用原游戏素材；无需 Three.js、游戏 ROM 或第三方素材服务。
- 精细美术 V2：五张本地原创素材图集 / 背景，覆盖木屋、树木、四向人物、守卫、彩蛋物件、室内和展品；画布支持最高 2 倍高清屏分辨率。生成方式、提示词方向和资源说明见 `assets/town-art-notes.md`。素材仅首次进入小镇时加载，失败时基础画面兜底。
- 三间房子有可走动室内：作品工坊的画框、放映小屋的照片墙 / 放映机、灵感书屋的书架。靠近展品互动打开内容，走到门口互动返回原来的屋外位置。
- 方向键 / WASD 移动，空格攻击，E 互动；M 切换全景地图，J 打开探索手册。手机横屏使用浮动十字键、A（攻击）和 B（互动）。
- 三处彩蛋：路边橘猫互动三次、许愿井互动四次、池塘边漂流瓶互动一次。解锁内容槽并记录发现；拜访三间房屋、解锁两只宝箱、发现三处彩蛋共 8 项探索记录。
- 每位守卫需要三次攻击；红框蓄力时退开一格可躲避。失去四颗爱心回到广场，已发现的宝箱保留。
- 打开内容、切换窗口、最小化、竖屏或离开页面时暂停；关闭窗口清理动画和监听。玩法面板可重新挑战两位守卫，不影响素材、收藏、房屋拜访和彩蛋发现。
- 不想玩也能通过内容目录直接访问所有展位。

### 如何补素材

1. 使用 `?edit=1` 打开网站，进入新游戏的“内容目录”（扭蛋机里叫“补充内容”）。
2. 选择展位 → “编辑这个展位” → 填写标题、介绍、完整内容链接，或上传图片 / 视频 / PDF → 保存。
3. 图片和视频可在内容卡中预览，附件可下载。支持常见栅格图片、MP4 / WebM / MOV / OGG 及 PDF，单个文件不超过 100 MB；实际视频解码能力取决于浏览器。出于安全考虑不接受 SVG / HTML。
4. 同一份内容自动用于扭蛋、房屋展位或对应宝箱。编辑时可移除附件或把文字清空，恢复占位。
5. 右上角“编辑内容”→“导出内容 JSON”，会包含 `arcade` 配置。附件仍需保留原文件；这些本地上传不会自动同步到 GitHub 或其他访客的浏览器。

正式发布时，把导出的 `arcade` 对象合入 `content.js` 的 `DEFAULT_CONTENT`，将附件复制到 `assets/`，为对应展位设置 `mediaUrl`（例如 `assets/my-work.jpg`）和 `mediaType`（例如 `image/jpeg`）。新访客无需本地上传即可看到这些已发布素材。

游戏配置与逻辑在 `arcade-core.js`，界面与编辑入口在 `arcade.js`，像素绘制在 `arcade-art.js`，样式在 `arcade.css`。挑战 / 抽取 / 收藏 / 拜访 / 彩蛋进度仅保存在当前浏览器的 `xiaosi-arcade-progress-v1`。未完成的重复互动次数不跨窗口保存。
